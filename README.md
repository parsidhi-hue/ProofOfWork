ProofOfWork

A Student Portfolio Platform

ProofOfWork is a web application that helps students showcase their academic and extracurricular achievements in one place.

Features

- User Signup and Login
- Personal Profile Management
- Add and Delete Portfolio Entries
- Categories: Projects, Certificates, Hackathons and Achievements
- Public and Private Portfolio Options
- Shareable Portfolio Link
- Portfolio Strength Score
- Category Filters and Live Search
- Evidence Links for Achievements
- Dynamic Dashboard Statistics

Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase (Authentication and Database)

Setup Instructions

1. Clone or download this repository.
2. Open the project in VS Code.
3. Configure your Supabase project.
4. Add your Supabase project URL and publishable key in "supabase-config.js".
5. Run the project using Live Server.

Database

The database schema is available in "db/schema.sql".

Supabase provides authentication, database storage and Row Level Security (RLS).

Project Goal

To help students build a professional digital identity by organizing and showcasing their skills, projects and achievements.
